Add `public func endElicitation(_ elicitationId: ULID, with response: ElicitationResponse) async -> Bool` on ToolContext. An accept gives false and changes nothing. The question ends only when it links to the holding run of the context (the same check as complete(elicitationId:)). The end goes through the run plane, so the end post goes out and the run gets the response with its reason. True only when a question ended. Multitool needs it.
