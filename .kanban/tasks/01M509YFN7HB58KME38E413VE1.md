title: ToolContext.elicit returns cancel with a reason at once when no user is present
---
Source: elicitation-plan.md, Extras task 18 (phase 2: headless and interactive).

When no user is present for a session, `ToolContext.elicit` returns `cancel` with a reason at once. It sends no question and it does not wait.

- No `elicitation` event goes to the sink.
- No question opens in the run plane.
- The reason is a public constant on `RunPlane`, in the same way as `RunPlane.runCancelledReason`.
- One value decides "a user is present" for a whole session. The host that makes the session sets it. The default is interactive, so current callers do not change.

Router and ACPAgent set the value later in their own tasks. This task adds only the Extras part.
