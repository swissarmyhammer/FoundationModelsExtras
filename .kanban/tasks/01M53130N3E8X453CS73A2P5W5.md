## Decision of the user (D-1)

- `pattern` is an ECMA-262 regex, and it is not anchored: the check is a search.
- `minLength` and `maxLength` count Unicode code points, not Characters.

## Exact rules (commit 8ea57d4)

### Length

- The length of a string value is the count of its Unicode code points (`String.unicodeScalars.count`; in JavaScript, `[...value].length`).
- It is not the count of Characters (grapheme clusters), and it is not the count of UTF-16 code units.
- Examples: `"e\u{301}"` has length 2. `"👍"` has length 1. `"👨‍👩‍👧"` has length 5.
- The failure text stays: `the field "<name>" must have <n> or more characters` and `... <n> or fewer characters`.

### Pattern

- The pattern is an ECMA-262 regular expression with no flags.
- The check is a search: the value is valid when the pattern matches a part of it. A pattern that must match the whole value starts with `^` and ends with `$`.
- The match works on Unicode code points, as ECMA-262 does with the `u` flag.
- A pattern that does not compile gives: `the pattern "<pattern>" of the field "<name>" is not a valid regular expression`.
- A value with no match gives: `the field "<name>" does not match the pattern "<pattern>"`.

### Translation to ICU (NSRegularExpression), outside a character class

- `\d` → `[0-9]`, `\D` → `[^0-9]`
- `\w` → `[A-Za-z0-9_]`, `\W` → `[^A-Za-z0-9_]`
- `\s` → `[\s\x{0B}\x{FEFF}]`, `\S` → `[^\s\x{0B}\x{FEFF}]`
- `\b` and `\B` → lookaround forms with the ASCII `\w` above
- `\v` → `\x{0B}`
- `.` → `[^\n\r\x{2028}\x{2029}]` (ICU `.` also refuses U+0085)
- `$` → `\z` (ICU `$` also matches before a final line terminator)
- `[]` → `(?!)` (matches nothing), `[^]` → `[\s\S]` (matches each code point)
- Each other part is copied.

### Translation in a character class

- `\d` → `0-9`, `\w` → `A-Za-z0-9_`, `\s` → `\s\x{0B}\x{FEFF}`
- `\D`, `\W`, `\S` → the nested sets `[^0-9]`, `[^A-Za-z0-9_]`, `[^\s\x{0B}\x{FEFF}]`
- `\b` → `\x{08}` (backspace), `\v` → `\x{0B}`
- `[` → `\[` and `&` → `\&` (ICU reads them as set operations)

### Gaps that stay

- Syntax that only ICU knows compiles here: possessive quantifiers, atomic groups, inline flags such as `(?i)`, `\Q…\E`, `\x{…}`, and the escapes `\A`, `\z`, `\Z`, `\G`, `\X`, `\h`, `\H`, `\V`, `\R`, `\N{…}`. ECMA-262 with no `u` flag reads an escape of a letter with no meaning as that letter.
- Syntax that only ECMA-262 knows does not compile here, and the field fails: a literal `{` that does not start a quantifier, `\u{…}`, a backreference before its group.
- `--` in a class, and a range next to a class escape such as `[\d-z]`, can have a different meaning.
- The names in `\p{…}` are the names of ICU.
