## What
The Router found that `ModelPool.progress(for:)` gets no download fractions when a caller acquires with its own loader (`acquire(_:footprintBytes:sessionBytes:loader:)`), and that the progress has no byte counts. So the Router maps the loader callback onto a fixed scale, and its `DownloadProgress` bytes are not real.

```swift
public enum ModelLoadProgress: Sendable, Equatable {
    case downloading(completedBytes: Int64, totalBytes: Int64)   // fraction = completed / total
    case loading, ready, failed(String)
}
```

- `Sources/FoundationModelsExtras/ModelPool/ModelLoadProgress.swift`: `downloading` carries real byte counts; add `var fraction: Double?` for the `downloading` case.
- `ProgressReportingDownloader.swift`: report the bytes of the Hugging Face download (completed and total over all files of the repository).
- `ModelPool.swift`: publish the progress of each load to `progress(for:)`, whatever acquire method and loader started it (the loader `progressHandler` goes to the pool stream for all acquire paths).
- `README.md`: the new case.
- Push to `origin main` when green, and tell the Router session (foundationmodelsrouter-d5) the revision.
