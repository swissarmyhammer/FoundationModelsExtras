## Rule T1

Remove each `.timeLimit`, `Task.sleep`, `BoundedWait` and `AwaitedCondition` sleep poll from the tests. Each wait in a test must also end on the failure event (the run settles, the session closes, the stream ends), or the test must fail before it waits.

## Known places

- RunPlaneCancelledRunQuestionTests: `.timeLimit`, and `deliveredAnswer` with `BoundedWait`.
- RunPlaneUserWaitTests: `.timeLimit`.
- MountFixtures `firstPendingElicitationId`: `AwaitedCondition`.
- ElicitationEndEventTests: a wait that can hang when the end is not posted.
