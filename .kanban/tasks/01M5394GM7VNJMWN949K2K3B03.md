title: 'Tests: no clock in the five waits that stay (DoctorRunner, ModelPool stress, DotfolderWatcher)'
---
Remove each clock, sleep, poll and deadline from five waits in the tests. A wait must end on the event that it expects, or on a failure event (cancel, error, stop of the watcher, end of a task).

## Design

1. DoctorRunnerTests `run(_:breakingADeadlockWith:)`: remove the watchdog sleep. Run `runner.run()` in a task with an executor preference for a test TaskExecutor that only queues jobs. The test pops and runs the jobs until the queue is empty. If the queue is empty and run() did not return, the runner is serial: set didFire, call breakDeadlock(), and continue until run() returns. If a default actor or a continuation resume does not run on the preferred executor and the test cannot be deterministic, stop this item and keep the old code.
2. ModelPoolTests `runStress`: replace the stress deadline with a direct lock-order check. Add an internal test hook in ModelPool (nil in production). The hook is called just before the yields in `publish(_:)` and before `delivery.send()` in `deliverProgress`. The test hook calls `state.withLockIfAvailable` and records if the lock was free. Show that the test fails when the yield moves into the state lock. Remove the stress tests that need the deadline. Keep each assertion that does not need the deadline, with no deadline. Remove `stressDeadline` and `stressExecutor` if they are not used.
3. DotfolderWatcherTests `waitForTheCancelHandlers`: remove the 10 ms poll. Add an internal awaitable signal on `openDescriptorCount`, fed where the count changes. The test waits until the count meets its condition.
4. and 5. DotfolderWatcherTests `waitForOSEvent(within:)` and `waitOutTheQuietWindow()`: add an internal event-source seam in DotfolderWatcher that opens a source for (path, event mask, queue) with an event handler and a cancel handler. The default wraps DispatchSource.makeFileSystemObjectSource and open/close as now. Unit tests inject a fake source factory and fire events by hand on the watcher queue. To prove "no further callback", the test empties the watcher queue (queue.sync) after the last fake event. Tests that must see real OS events move to the IntegrationTests package, with no deadline.

Also remove each helper in Tests/FoundationModelsExtrasTests/Waits.swift that becomes unused.

## Rules

- No clock, Task.sleep, poll loop, retry, .timeLimit or deadline in Tests/ and IntegrationTests/.
- No public API change. Internal test hooks are permitted.
- One full `swift test` run at the end.
